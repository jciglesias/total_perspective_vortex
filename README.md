# total_perspective_vortex

A machine learning project focused on decoding mental states from electroencephalographic (EEG) signals. The goal is to build a brain-computer interface capable of inferring a subject’s intended action or cognitive state from a sequence of EEG measurements over time.

This work explores the intersection of signal processing, neuroscience, and predictive modeling. By transforming raw EEG data into meaningful features and training classification models, the project aims to distinguish between discrete states or movements in a time window from $t_0$ to $t_n$.

## Project focus

- EEG-based signal analysis and preprocessing
- Feature extraction from temporal brain activity
- Classification using machine learning techniques
- Evaluation of model performance on brain-state prediction tasks

## Technical goals

The system is designed to use a subject’s neural activity to predict whether they are engaged in one of two conditions, such as motion A or motion B, based on patterns present in the recorded signal. The project highlights how data-driven methods can be applied to decode complex, noisy biological signals into actionable predictions.

## Stack

- Python
- NumPy / pandas for data handling
- Signal processing and feature engineering
- Machine learning models for classification

## Outcome

The project demonstrates an end-to-end approach to EEG analysis, from raw sensor data to interpretable model-based predictions, with the broader aim of advancing human-computer interaction and cognitive signal decoding.
